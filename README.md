## Загрузка и сохранение Wavefront OBJ

Отдельное приложение `obj_viewer.py` использует существующие геометрические
классы, матрицы преобразований и интерфейс. Дополнительные пакеты не нужны
(требуется Python с tkinter).

Запуск из каталога `affine_transformations_projection`:

```powershell
python obj_viewer.py
python obj_viewer.py "C:\Users\79515\Downloads\utah_teapot_lowpoly.obj"
```

- **Файл → Открыть OBJ…** (`Ctrl+O`) — загрузить и показать модель.
- **Файл → Сохранить OBJ как…** (`Ctrl+Shift+S`) — сохранить текущие координаты
  и грани после преобразований.
- Панель слева: перемещение, поворот, масштабирование, отражение и вращение
  вокруг оси через центр или произвольной прямой.
- ЛКМ с перетаскиванием вращает камеру, колесо меняет экранный масштаб.
- **Файл → Подобрать вид** (клавиша `F` при фокусе на холсте) показывает модель
  целиком, сохраняя её координаты. После большого перемещения или увеличения
  можно подобрать вид повторно.
- **Сбросить фигуру** возвращает исходную загруженную модель. Список
  многогранников позволяет выбрать фигуры лабораторной №6 и сохранить их в OBJ.

Поддерживаются `v`, `f`, многоугольные грани, положительные и отрицательные
индексы, ссылки вида `v/vt/vn` и `v//vn`. Импортируется и сохраняется геометрия;
текстуры, материалы и заданные в файле нормали не переносятся. Освещение
вычисляется по геометрии граней. Отрисовка использует сортировку граней по
глубине без Z-буфера: у пересекающихся граней возможны ошибки перекрытия.
